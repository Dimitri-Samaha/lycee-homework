# Lycée Homework

These are high school ("lycée") math and programming homework scripts, mostly written in French.

- `vacation_homework_1.py`: two unrelated exercises, a spending fee calculator and a recursive simulation of village growth.
- `vacation_homework_2.py`: four short exercises covering dog to human age conversion, BMI calculation, a group pricing tier, and a small recurrence sum.
- `fibonacci.py`: the Fibonacci sequence.
- `iteration_vs_recursion.py`: the same recurrence solved both iteratively and recursively, for comparison.
- `quadratic_equation.py`: solves `ax² + bx + c = 0`, reporting the discriminant and the root or roots.
- `bacteria_growth.py`: recursive bacteria population growth, finding how many generations pass until a population threshold is crossed.

## Requirements
The standard library is enough.

## Running it
```
python fibonacci.py
```
(or any other file directly, since each is a standalone script)
