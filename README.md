# Lycée Homework

High-school ("lycée") math/programming homework scripts, mostly in French.

| File | What it does |
|---|---|
| `vacation_homework_1.py` | Two unrelated exercises: a spending-fee calculator and a recursive village-growth simulation |
| `vacation_homework_2.py` | Four short exercises: dog-to-human age conversion, BMI calculation, a group-pricing tier, and a small recurrence sum |
| `fibonacci.py` | Fibonacci sequence |
| `iteration_vs_recursion.py` | The same recurrence solved both iteratively and recursively, for comparison |
| `quadratic_equation.py` | Solves `ax² + bx + c = 0`, reporting the discriminant and root(s) |
| `bacteria_growth.py` | Recursive bacteria population growth, finds how many generations until a population threshold is crossed |

## Requirements
Standard library only.

## Running it
```
python fibonacci.py
```
(or any other file directly — each is a standalone script)
